# Fjällklätterprojektet

## Description

This repository is for developing and hosting (using GitHub Pages) the website of Fjällklätterprojektet, which aims to popularize climbing in the Swedish mountains by documenting and publishing information about climbing routes and areas (see [https://fjallklatterprojektet.github.io/in_english.html](fjallklatterprojektet.github.io/in_english.html) for more info about the project).
